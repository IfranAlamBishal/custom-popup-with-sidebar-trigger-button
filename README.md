# 🎯 Custom Newsletter Popup Section
## Overview

The Custom Newsletter Popup Section is a clean and modern popup designed to collect customer emails while promoting offers such as first-order discounts.

It features a promotional image, customizable content, newsletter signup form, floating trigger tab, and trust badges.

Perfect for:

  - Newsletter signup
    
  - First-order discount offers
    
  - Promotional campaigns
    
  - Customer engagement
    
  - Product and brand announcements

The section is fully customizable through the Shopify Theme Editor and optimized for all devices.

# ✅ How to Install

## 1. Open Your Shopify Theme Code Editor

  - From Shopify Admin, go to Online Store → Themes
    
  - Find your active theme and click ⋯ → Edit code
  
## 2. Create a New Section

  - Open the Sections folder
  
  - Click Add a new section
  
  - Name it, for example: newsletter-popup.liquid
  
  - Paste the full code
  
  - Click Save

# ✅ How to Use

## 1. Add Section

  - Go to Online Store → Themes → Customize
  
  - Add the Newsletter Popup section to your desired page

## 2. Customize the Popup

  You can configure:

   - Promotional image
  
   - Logo
  
   - Popup heading and message
  
   - Display delay
  
   - Email signup button
  
   - Colors and typography
  
   - Floating trigger tab
  
   - Trust badges

## 3. Add Trust Badges

  The section supports up to 3 trust badges.
  
  Each badge can include:

   - Icon
  
   - Title
  
   - Sub-text

# 🧩 Tips

  - Keep the promotional message short and clear
  
  - Use a high-quality product or lifestyle image
  
  - Use 2–3 trust badges for better balance
  
  - Keep the CTA simple and action-focused
  
  - Disable Test Mode before going live
  
# ⚠️ Troubleshooting

  - Popup not appearing?
    → Check the popup delay and Test Mode settings.
  
  - Trigger tab not showing?
    → Make sure Show Trigger Tab is enabled.
  
  - Image not showing?
    → Check that a promotional image has been uploaded.
  
  - Popup looks unbalanced?
    → Try using a suitable image and keeping the content concise.
